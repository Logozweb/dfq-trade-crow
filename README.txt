DFQ Trade Crow v4 — Modular HTML / CSS / JS + PHP / MySQL Bundle
==================================================================
Folder Structure:
- index.html               -> Main Marketplace UI
- dashboard.html           -> Trader Workspace & Offers UI
- trader.php               -> Public Trader Storefront
- ticket.php               -> Printable Digital Pawn Receipt
- admin.php                -> Admin Moderation Panel
- assets/css/style.css     -> Separated Global Stylesheet
- assets/js/app.js         -> Separated Marketplace Logic
- assets/js/dashboard.js   -> Separated Dashboard Logic
- api/schema.sql           -> MySQL Database Schema
- api/config.php           -> Database & Email Config
- api/auth.php             -> Auth & Referral API
- api/items.php            -> Listings, Serial Check & Wishlist API
- api/offers.php           -> Swap Offers, Escrow & Ratings API
- uploads/                 -> Protected Image & Receipt Storage
